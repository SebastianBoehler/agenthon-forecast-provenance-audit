## Executive summary (read this first)

This local review package contains the current canonical TeX manuscript, posthoc
expression-semantic AI reviews, a separate unused-group quantity-reminder study,
its V1 primary judgments and V2 pointer-format diagnostic, and saved independent
numerical accounting. The prior followup-review ZIP is nested unchanged under
`historical/`. This is review evidence, not a submission or public-release receipt.

The manifest binds the paper's current bytes and every included file. Its spend
is computed from observed settled billing in the shared ledger; it includes paid
authored preflights and V1/V2 financial calls. A closed stop with unknown settled
billing is preserved with a known subtotal, explicit unknown cost and its reserved
amount. The full observed total remains null; reservation accounting is never
reported as actual billed spend. Pending/unsettled calls prevent packaging.
Older historical manifests keep their
original paper hashes and cost scopes.
The current-paper native-compilation receipt is required and hash checked.
Rendered page count remains unverified; this package does not certify nine-page
compliance.

## Portable arithmetic replay

Extract this ZIP into an empty directory. With Python 3.11 or later, run:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python scripts/analyze_finance_quantity_transfer.py \
  --portable-input outputs/finance-quantity-transfer-v1/independent-analysis/portable_numeric_packet.jsonl \
  --output reviewer-numerical-replay
```

This source-free replay checks strict saved-answer schema, typed-unit/scale
normalization, reported-value and safe-expression numerical agreement, and the
separate literal native-numeric channel. It re-aggregates previously validated
judge and pointer-accounting flags; it does not rerun grounding or pointer lookup
against omitted contexts. It makes no model calls and needs no API key or weights.
The original local full-analysis and separate compact-replay receipts are included.
Hash validation of omitted local inputs requires those inputs to be acquired
separately; their listed hashes do not make them present in this ZIP.

## Evidence and omissions

Included semantic reviews and provisional references are AI technical readings
under stated assumptions. Numerical agreement, two-reviewer support and a
same-model judge verdict are distinct measurements; none is qualified expert
truth. The 131 posthoc expression records share 58 questions and do not represent
131 independent questions. The unused-group study preserves all 64 planned
answer/judge pairs, including ten questions outside its provisional numeric subset.
V2 stopped after 23 financial attempts: 22 returned and one HTTP 502 without
observed billing; 41 were not started. All 64 remain its planned denominator.
The shared known observed subtotal is $0.061335771 with one unknown cost. Its
$0.002311197 reservation gives $0.063646968 accounted under fixed request prices;
that sum is not observed actual spend. No retry or additional paid call follows.

The new iteration tree excludes full financial-report contexts, question,
experiment and review packets, original native annotations/programs/source-target
files, private outcome join keys, raw request bodies/provider responses, keys,
environment files, caches and weights. Numeric native values in the projected
replay are a separate literal diagnostic, not original evaluator reconstruction.
Included schema/location tests use authored examples only.
The human-review preparation receipt and blank form are included. No reviewer has
been recruited and no human annotation has been produced; the corresponding
question/context packet and private identity map remain excluded.

These omissions prevent full prompt replay, source-grounding validation and full
semantic re-adjudication from this package. The prior archive is an unchanged
historical object with its own README and omissions; extract it separately and
follow its original replay instructions without overlaying the current paper.

## Local build command

Only after the paper, closed V1/V2 runs, independent results and saved compact
replay are final, execute from the author repository:

```bash
.venv/bin/python scripts/package_semantic_transfer_review.py
```

The builder uses a fixed whitelist and refuses to overwrite any prior ZIP,
manifest or receipt. It rejects context/request/credential fields in included
JSON and checks the immutable prior ZIP hash. A failed generated archive is
retained for inspection; the builder provides no automatic replacement or fallback.
The incomplete V2 execution is retained as a failed diagnostic with limited
coverage; its returned-case verdicts cannot support a complete-panel comparison.
