## Executive summary (read this first)

The proposed paper is **not novel as “looped transformers for finance,” “iterative forecast refinement,” or “text-guided forecasting.”** Each is already represented in close prior work. A potentially defensible question remains: whether dated evidence changes the *value of extra recurrent computation* for a calibrated probabilistic forecast under an equal inference budget. The current FOMC/DGS10 pilot can test feasibility, but its fixed three-pass loop cannot establish that adaptive computation responds to evidence. With roughly one FOMC event every six weeks, it also has limited power for a transformer comparison. Do not turn a positive pilot score into a poster claim without a distinct mechanism and replication.

## What could still justify a paper

**Researchable estimand:** the difference between the effect of additional recurrent passes with relevant as-of text and the effect of the same passes with withheld or semantically neutral text, measured by held-out proper score and actual inference cost. Report this as an interaction, not a generic main-effect speedup. Use a one-pass text-conditioned model, no-text loop, equal-compute untied depth, Dudley-style feedback loop if feasible, and a simple probabilistic baseline. A text-routing comparator or at least an explicit comparison to AIR is needed before claiming a novel mechanism.

The analysis must distinguish **fixed recurrence** from **evidence-adaptive recurrence**. To claim the latter, the number of passes has to vary using information available at the forecast date, with the gating policy trained before test dates. If every example receives three passes, any measured difference is evidence of fixed-depth text interaction only. Compare an equal *expected* compute budget and include gate error/latency; otherwise adaptation wins by spending more.

## Methodological red flags in the frozen pilot

1. **Small, correlated event sample.** The proposed 2000–2025 FOMC statement days likely yield only a few hundred records. Transformer variance, nonstationarity, overlapping policy cycles, and post-selection on one 2023–2025 holdout can dominate the effect. Report sample counts before training, confidence intervals with date blocks, and a deliberately simple baseline. Three seeds alone do not solve data uncertainty.
2. **Time-of-information precision.** Official statement date is not an exact release timestamp; statement-day DGS10 is an end-of-day value. An “evening after statement” forecast is coherent, but it may already contain the market response to the statement. The target is the *next* daily change, so signal may be weak. FRED DGS10 is a revised series, not vintage-exact point-in-time market data. These limits need to be explicit.
3. **Semantic control quality.** Randomly shuffling statements across dates changes era, monetary regime, length, and writing style. Add controls that preserve period/style while changing content, or limit conclusions to identity sensitivity. A text token whose effect survives semantic disruption is not evidence use.
4. **Score and distribution mismatch.** Gaussian negative log likelihood and analytic Gaussian CRPS are valid for a narrow pilot, but finance tails may be non-Gaussian. Show coverage/calibration, sharpness, outliers, and compare a simple scale-calibrated forecast. A CRPS gain alone cannot establish robust tail modeling.
5. **Baseline fairness.** A three-pass tied block versus three untied blocks differs in parameter count and training capacity. The pilot says approximate attention compute; measure actual runtime and model sizes, match training budget, and state which factor each contrast isolates.
6. **No untouched confirmation after iteration.** Selection on 2019–2022 validation is acceptable; repeated peeks at 2023–2025 test while revising the model would invalidate confirmatory claims. Keep the first pilot exploratory if its outcome drives a redesign.
7. **Scope mismatch.** This independent DGS10 experiment is related to Agenthon T2, but has one asset, one horizon, and public dated statements, whereas T2 also evaluates cross-asset dependencies and shock tails. Avoid implying that a pilot effect predicts T2 leaderboard performance.

## Decision

Proceed with the frozen pilot as a **kill test** of data sufficiency and measurable interaction. If fixed-depth recurrence does not beat equal-compute depth and simple calibrated baselines under date-held-out CRPS, or if text semantics do not affect the gain, stop this paper framing. If it does, next write the one-page gap argument around the interaction, conduct an independent adversarial review of the nearest works and protocol, and obtain a genuinely separate confirmation set before claiming a contribution. The literature does not support confident acceptance from the current design.
