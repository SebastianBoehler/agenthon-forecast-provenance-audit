## Executive summary (read this first)

This final iteration holds each response fixed while comparing answer extraction,
numeric equivalence and financial target selection. It adds a known mathematical
benchmark without claiming a new model, general semantic verifier, population error
rate or downstream training effect. Two available local model families, three
stochastic repetitions and 16 frozen questions produce 96 scheduled requests.
No paid inference is authorized in this iteration.

The protocol and code are hashed before any cohort generation. Earlier authored
RecursiveMAS examples motivated the study and remain post-discovery diagnostics.
The new controls are rule-generated over the complete admitted reference census.

### Data and admission

Pin all 500 native MATH500 rows and the mirror card by revision and byte checksum.
Census every reference. Admit only a signed integer, finite decimal, simple p/q
fraction or integer-numerator LaTeX fraction, optionally enclosed in a whole-answer
math/box wrapper. Other expressions abstain. No approximate equality is used for
MATH500. A terminating decimal is a positive control only when exactly equal.
Admission depends only on this declared grammar, never on the native grader or a
model output. Report all exclusions. This is reference-value agreement, not an
expert certification that every question's intended answer is a unique scalar.

Hash-select eight admitted questions without approximate/rounding wording flags.
Keep the all500 census and this local subset's denominators separate.
Select two previously unused question groups in each of four pinned Cosimo
families: constructed-response Gordon, binomial calls, ordinary Gordon and WACC.
Exclude the original 200-question hash manifest before selection. Independent
Fraction arithmetic must agree with the visible-input Decimal target.
Binomial prompts explicitly declare simple compounding. All models receive the
same final-scalar instruction; units are fixed by financial family.

### Controls and comparators

For every admitted MATH500 reference generate identity, reduced and unreduced
fractions, and exact terminating decimals as positives. Shift by 1/10 and 1, and
flip a nonzero sign as independently value-changing negatives. All controls are
checked by exact rational arithmetic. These are deliberately authored stress
tests, not sampled model-error prevalence.

Compare the pinned RecursiveMAS MATH500 comparator, its normalization ablations
(remove integer-part, remove digits-only, remove both), literal equality and exact
rational equality. Shared-scalar comparisons hold extraction fixed. Compare the
unchanged native full-response extractor separately; a parser abstention is not
an incorrect scalar. The RecursiveMAS implementation is not the official MATH or
PRM800K grader, and its current revision is not bound to historical paper scores.

Financial scoring compares the reconstructed released-label cent-tolerance policy,
the corrected financial contract with integer-rounding compliance, and an
unrounded cent-tolerance ablation. Label repair and tolerance/rounding repair are
separate. These financial endpoints are not the RecursiveMAS native evaluator.

### Local collection and failure accounting

Use LM Studio's native chat API and embedded tokenizer/chat template. Gemma 4 E2B
and Qwen3.5 9B use existing Q4_K_M checkpoints and 4096-token contexts. E2B means
effective size; loaded metadata reports 4.6B total. This family comparison cannot
identify a causal size effect. Hash model bytes and save load settings. Use
temperature 0.2, top-p 0.95, top-k 40, no tools, reasoning off, max1024 output tokens.
Three repetitions are stochastic and unseeded; raw responses enable exact score
replay, not guaranteed identical regenerated samples. Hash-sort question order
separately by repetition. Save every scheduled attempt, raw response, request,
native token counts, elapsed time and error. No retry or model/case replacement.

Three source-free arithmetic probes precede collection. Interface validation
checks token accounting and context headroom. Report errors, capped replies and
unsupported/missing final answers separately. Use the same saved reply for every
paired score. Do not treat repeated replies or synthetic templates as independent
datasets. Report finite counts per model/repetition, not inferential significance.

Exact-control disagreement blocks collection. No observed natural disagreement
means no natural grading-effect claim. Any discrepancy must have an inspectable
scalar/target record. A simple exact baseline solving the issue is a useful result.
Do not train a tiny RL policy merely to rediscover a deterministic collision; a
learning extension needs separate exploit-discovery or held-out transfer evidence.
