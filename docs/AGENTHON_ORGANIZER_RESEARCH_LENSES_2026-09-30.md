### Concrete paper structure to make these checks easy

These are editorial/scientific recommendations, not a secret venue rubric:

1. Open with the call-price/financing-debt example and the exact empirical question.
   State the narrow contribution and closest-work boundary immediately.
2. Define four layers once: visible financial task, released source annotation,
   model response contract, and native/adapted scoring. Keep quantity, units,
   explicit rounding and input uncertainty distinct throughout.
3. Present source admission, revisions, duplicate/context units, independent
   formula checks and passing controls before error totals. Put conditional
   precision findings beside their assumptions, not inside definite-error totals.
4. Report fixed-output grading matrices with failure and conditional denominators.
   Separate original strict, exploratory recovery, legitimate native convention
   and quantity-grounded outcomes. Never label a broad-unit match financial truth.
5. Treat document transfer as corroboration/diagnosis, with known prior repairs and
   disputed readings visible. Treat GEPA and abandoned branches as feasibility
   history, preserving the null result without promoting it into new methodology.
6. End with what an evaluator/data maintainer could check today and what remains
   unmeasured. Keep the artifact reproduction path prominent; leave most failed
   branch detail in the appendix/index so the central argument remains readable.

### Follow-up experiments, ranked by what they resolve

**First: measurement-matched prompt control.** Run a new, separately frozen
baseline/reminder comparison with identical schema, executable-calculation grammar,
precision policy and resource limits. Keep assumptions outside the expression
field. Native tokenization, context retention and source-free format preflight are
plumbing gates. One cached additional family can test robustness if feasible;
adding many checkpoints is not the scientific objective. Preserve transport and
schema failures and report numerical changes separately from representation changes.
This resolves the known prompt confound; it does not establish a new method.

**Second: quantity-grounding falsification of saved expressions.** Inspect all
131 supported/locked-eligible responses, including passes and failures, under a
new disclosed posthoc rubric. Test whether the 47 reported-mismatch→executed-match
transitions survive requested-quantity, time-index, denominator and stricter unit
attribution. Preserve the original broad-unit scores and unresolved readings.
No answer extraction, guessed units or source-gold-guided repair is admissible.
This attacks a substantive inference weakness without fresh model calls.

**For a later main-track study:** admit previously uninspected independent
producer/task lineages before defect selection; obtain domain adjudication before
targets are opened; evaluate a frozen audit/correction procedure on those cases.
If claiming optimization consequences, require successful objective movement,
matched feedback/tolerance, passing-family controls, manual baselines, repeated
runs and genuinely external financial evaluation. If the source and financial
objectives remain aligned, retain that falsification. A new architecture is
justified only by a mechanism-specific hypothesis, not organizer-topic matching.
