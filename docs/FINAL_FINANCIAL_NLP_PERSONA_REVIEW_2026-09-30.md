### Controls that distinguish equality from a convenient normalization

| Control | Construction and check | What it establishes |
| --- | --- | --- |
| Identity | Original admitted reference as the single final answer | Extraction/dispatch and baseline credit; retain any failure |
| Equivalent fraction | Reduced `p/q` versus `2p/2q`, with exact equality checked | Credit across an explicitly admitted representation change |
| Equivalent decimal | Exact decimal only when the reduced denominator has factors 2 and 5; otherwise inapplicable | Representation preservation without approximate repeating decimals |
| Unequal offset | Fixed `r+1` and `r+1/10`, each proved unequal to `r` | Integer and nearby scalar negative controls |
| Unequal sign | `-r` only when `r != 0` | Sign preservation; do not count `-0` as an error |
| Fraction perturbation | `(p+1)/q`, with inequality checked before scoring | Value change that retains a fraction representation |
| Mechanism-targeted collision | Fixed, predeclared same-truncation-bin construction; skip/report accidental equality | Conditional diagnostic of the inspected failure, not natural model frequency |

Use the actual native `Final Answer:` extraction path and fixed output wrapper for every control; store raw reference, candidate, parsed Fractions, extracted strings, native decision and rational decision. A scalar-only comparator operating after extraction is a useful secondary endpoint, but must not be confused with the original wrapper's acceptance. Reject multiple conflicting final answers in the strict independent endpoint.

Show both invalid credit and equivalent-form rejection. A new scorer that rejects every variant is not a successful repair. Add an exact-string baseline to demonstrate its expected representation limitations. For a mechanism ablation, record individual native strategy matches or omit one strategy at a time in a separately named diagnostic. Preserve the original OR comparator unchanged for the main contrast. Do not claim all observed collisions arise from signs when truncation already credits them.

Authored perturbation acceptance is a **challenge-set false-credit rate against the released rational reference**, not benchmark score inflation. Natural saved model outputs provide a separate paired score difference. Establishing historical published-score effects would require the historical evaluator revision and actual raw outputs.

### Tiny optimization: stop unless the hypothesis changes

A contextual bandit chooses among candidate actions using rewards; it need not simulate a multi-step environment. Training it to output a known same-integer-bin value when the target is available is an oracle-conditioned demonstration. A one-line mutation or fixed action-frequency baseline already answers that question. Parameter count, fast training and PufferLib throughput do not create novelty.

[Egashira et al., arXiv:2605.02909v2, §§3–4 and limitations](https://arxiv.org/html/2605.02909v2) already analyze and experimentally test systematic verification errors, including false-positive regions, plateau/collapse and dependence on the induced behavior. Their LLM training experiments are considerably stronger evidence of learning consequences than an action selector exploiting a published normalization. Our release-specific defect could be a useful real-error case; a toy selector cannot be presented as a new RLVR mechanism or proof of training harm.

Only consider learning later if it tests whether **label-free, question/output features** predict exploitability on untouched groups under a real released reward interface, with identical native-versus-corrected training arms, fixed action sets, matched budgets/seeds and independent held-out correctness. Compare uniform action, best constant action, a fixed analytic rule, and the simplest learned model first. Provide no target, source identifier proxy or independent correctness feedback to the native-reward arm. If correct targets are supplied to construct candidate actions, disclose that oracle access explicitly; the experiment then measures action selection, not solving the task.

The required result would be a reproducible held-out divergence between assigned reward and independent correctness that an analytic baseline does not already explain. A failure to outperform that baseline is a principled stop. This design is not established by the present census, and no training is recommended for the deadline iteration.
