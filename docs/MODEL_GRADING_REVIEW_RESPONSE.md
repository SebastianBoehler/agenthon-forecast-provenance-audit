making later analyses identifiable. The contribution is external evidence about

## Remaining boundaries

The numerical contracts depend on specified family formulas and assumptions.
They are not general automatic judges. Numerical compatibility does not certify
a derivation. The binary graders are reconstructed sensitivity conditions, not
executed original rewards. Human packets are prepared with blank sheets.
The current source is kept in the same native LaTeX editor; no replacement
document, additional editor tab or separately compiled paper PDF is created.
External submission and public release require their own authorization.
