as a predeclared positive result. Its final object is an empirical supervision audit.

is bounded by direct primary literature collisions.

## Implementation and interpretation changes

The first new execution failed because the package had not been installed editable.
Installing the local package resolved discovery of `answer_contract`. An operand regex
then consumed CAPM's sentence-final period; a structured numeric regex fixed parsing.
No partial result was accepted after either failure.

The primary census revealed CAPM's hidden beta precision. The initial broad interval
was narrowed after independent source inspection; previous outputs and code were saved
in `outputs/answer-contract-v1/snapshots/before-beta-only-amendment/`. The formula-only
ablation was corrected to retain cent serialization rather than a half-unit allowance.
Nearest-integer tie acceptance was clarified. Original discrepancy counts did not change.

Distinct-prompt conflict counts initially selected the first duplicate's label. Because
hidden beta can generate different labels for identical displayed questions, that
count was replaced by prompts with any conflicting label; CAPM becomes 836/991.
This corrects aggregation without altering any row-level finding.

Independent Fraction arithmetic checked 5,935 values and the actual exported numerical
patches. The manuscript review then narrowed rounding semantics, documented oracle
consistency, added the successful simple baseline, explained seeded common-mode
verification, corrected references and clarified D0. No model training was introduced.

The standalone LaTeX draft uses embedded chart coordinates for native compilation.
Separate Matplotlib figures use figures4papers design conventions and tueplots.
Export checks exposed a long revision-hash line and crowded plot labels; abbreviated
pins with full hashes in the manifest and two-line axis labels resolved the layout.

## Artifact binding

`outputs/answer-contract-v1/manifest.json` binds inputs, code, protocol/amendments and
analysis outputs. `outputs/answer-contract-independent/summary.json` binds independent
source inspection, formulas, source preferences, review sampling and materialized
patch checks. Figure metadata binds plotting code, data, style and exports.
The current submission bundle manifest binds the manuscript source, figure exports,
review documents and reproduction code. The native editor supplies the paper preview;
no separate manuscript PDF is exported. This is ARA-inspired artifact practice,
not formal compliance.
