## Executive summary (read this first)

This archive preserves 61 files from abandoned forecasting, market-cycle, MarS and
blinded-packet branches before removing them from the active repository. It includes
code, recorded outcomes, earlier proposals and the retrospective exploration graph.
These branches are not evidence of a successful method in the submitted paper.

`retired-branches-manifest.json` records the pre-cleanup Git commit, each retired
file's SHA256 and the ZIP's SHA256. The ZIP retains each original relative path and
an internal manifest. The earlier Git tree remains available at the recorded commit.
Hash identity establishes what was preserved, not experimental validity.

Extract into a separate directory to inspect or run historical tools with their
original inputs. Full corpora, model weights and all training/inference runtime
inputs are not included in this small archive. The separate preserved original
research package retains its own evidence and freeze identities.

The MIT license covers the author's code; external resources retain their recorded
licenses. Do not overlay this archive onto the current checkout: its entry points
and protocols deliberately describe the earlier branches.
