## Executive summary (read this first)

This complete 96-attempt scalar bank adds local Llama 3.2 3B and a fixed-provider
GLM-4.7-Flash API arm to the original 16-question panel, with three repetitions.
All questions and scoring endpoints are inherited; these are exploratory extensions
chosen after earlier results, not model-family or capacity comparisons.

```bash
PYTHONPATH=src python scripts/replay_final_extensions.py
```

The manifest binds protocol snapshots, all response projections, numerical counts
and recorded API usage. Replay uses the original bank's cohort projection and
recalculates every scalar decision. Raw financial/mathematical question contexts
and explanatory replies are omitted; full-response extraction requires the retained
original records. Hosted templates and weights are not independently pinned.

GLM receives 7 released-label versus 17 contract credits on 24 financial attempts.
Llama has no valid financial answer, so its zero denied-valid count is uninformative.
In mathematics, two repeated Llama answers of zero receive integer-part credit
against one question's 10/11 reference. The manuscript supplies the elementary
identity; these are two replies to one question, not independent failure replications.

A first Llama readiness stage generated no replies: the native API rejected an
unsupported reasoning selector. Its frozen collector/protocol and failed probes
are retained. The amended stage omitted that selector before cohort collection,
kept the scientific parser unchanged and retained every scheduled result.
The GLM ledger records 51 paid requests including three source-free probes,
$0.00286891 observed usage, one Novita BF16 route and no retries or fallback.
Exact saved-value replay does not certify financial meaning or reproducible API weights.
